# Reply Bubble V1

## Scope
- tap/click a message bubble to set reply target
- reply preview shown above composer
- send text message includes `reply_to_message_id`
- reply messages render a quoted snippet above message content

## Notes
- implemented as a small UI layer on top of existing messages flow
- no sticky header or auto-scroll included in this phase
- next phase can add jump-to-original and highlight behaviour
